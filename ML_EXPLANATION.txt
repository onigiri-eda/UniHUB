================================================================================
                    MACHINE LEARNING SYSTEM - PROJECT OVERVIEW
                              UniHUB Recommendation Engine
================================================================================

PROJECT CONTEXT
===============
UniHUB is a university recommendation system that helps students find the best-fit
university in Kazakhstan based on their preferences, specialization, location, and
academic priorities. The ML system analyzes student survey responses and recommends
one of four universities: IITU, AITU, KBTU, or UIB.

The survey collects 5 key inputs from students:
1. Specialization (20 options: Computer Science, AI, Engineering, Business, etc.)
2. Preferred City (Astana, Almaty, or Other)
3. International Experience Importance (High, Medium, Low)
4. Budget Level (High, Medium, Low)
5. Priority (Innovation, Quality, Reputation, Career)

================================================================================
                            ARCHITECTURE OVERVIEW
================================================================================

Instead of using TensorFlow.js (which had initialization issues), we implemented
a DECISION TREE + SCORING ALGORITHM approach, which is:
- More reliable (no external ML library dependencies)
- Faster (instant predictions, no model loading)
- More interpretable (clear reasoning for recommendations)
- Production-ready (no silent failures)

The system has 3 main components:
1. TRAINING DATASET: 200+ labeled scenarios
2. DECISION TREE: Rule-based specialization → university mapping
3. SCORING ALGORITHM: Multi-level matching with weighted bonuses

================================================================================
                            TRAINING DATASET
================================================================================

The training dataset contains 200+ scenarios, each representing a student profile
and their best-fit university. The dataset was manually created based on domain
knowledge about each university's strengths.

DATASET STRUCTURE (JSON objects):
{
  spec: "Computer Science",           // Specialization
  city: "Astana",                     // Preferred city
  intl: "High",                       // International importance
  budget: "High",                     // Budget level
  priority: "Innovation",             // Priority preference
  best: "aitu"                        // Best university match
}

HOW THE DATASET WAS BUILT
==========================

1. SPECIALIZATION → UNIVERSITY MAPPING (Domain Analysis)
   
   IT/Computer Science Specializations → AITU (AI-focused) & IITU (Diverse IT)
   - Computer Science
   - Software Engineering
   - Cybersecurity
   - Cloud Computing
   - Artificial Intelligence
   - Data Science
   - Communications
   - Digital Media
   
   AITU (Astana IT University) emphasis: Innovation, modern tech, AI/ML focus
   IITU (International IT University) emphasis: Quality, diverse programs, established
   
   
   Engineering Specializations → KBTU (National Engineering University)
   - Engineering
   - Civil Engineering
   - Mechanical Engineering
   - Oil and Gas
   - Architecture
   
   KBTU emphasis: Technical excellence, industrial partnerships, research


   Business Specializations → UIB (University of International Business)
   - Business Management
   - Finance
   - Marketing
   - Project Management
   - Entrepreneurship
   
   UIB emphasis: Business reputation, international curriculum, career focus


2. GEOGRAPHIC WEIGHTING (City Preferences)
   
   Astana:
   - AITU gets +15 points (capital location, modern campus)
   - General tech focus aligns with Astana growth
   
   Almaty:
   - IITU gets +10 points (oldest, most established in Almaty)
   - KBTU gets +10 points (strong engineering presence)
   - UIB gets +10 points (business hub)
   
   Other Cities:
   - Defaults to parent specialization category


3. PRIORITY-BASED VARIATIONS
   
   Innovation Priority:
   - AITU gets +10 points (newest, cutting-edge tech)
   - Suits: AI, Cloud Computing, Startup-minded students
   
   Quality Priority:
   - KBTU gets +8 points (engineering rigor)
   - UIB gets +8 points (international accreditation)
   - Suits: Engineering, Business specializations
   
   Reputation Priority:
   - UIB gets +8 points (business reputation)
   - KBTU gets +5 points (engineering prestige)
   - Suits: Career-focused business students
   
   Career Priority:
   - UIB gets +8 points (strong industry connections)
   - KBTU gets +5 points (employer network)
   - Suits: Business and engineering students


4. INTERNATIONAL EXPERIENCE IMPORTANCE
   
   High International Importance:
   - AITU gets +10 points (partners with global tech hubs)
   - IITU gets +5 points (international in name)
   - Suits: Students wanting study abroad, international exchange
   
   Medium/Low International:
   - No additional bonus
   - Default recommendations apply


5. BUDGET CONSIDERATIONS
   
   The dataset includes variations at different budget levels:
   - High budget students get premium universities
   - Medium budget students get balanced options
   - Low budget students still get quality matches
   
   Budget doesn't directly boost scores but affects filtering

================================================================================
                         DATASET GENERATION PROCESS
================================================================================

The dataset was generated in multiple phases:

PHASE 1: BASE SCENARIOS (80-100 scenarios)
=========================================
For each specialization category, we created base scenarios:

Example IT Category:
  Computer Science + Astana + High Int'l + High Budget + Innovation → AITU
  Computer Science + Almaty + High Int'l + High Budget + Quality → IITU
  Computer Science + Almaty + Low Int'l + Medium Budget + Quality → IITU

Example Engineering Category:
  Civil Engineering + Almaty + High Int'l + High Budget + Quality → KBTU
  Mechanical Engineering + Almaty + Medium Int'l + Medium Budget + Career → KBTU

This creates clear decision paths for each specialization.


PHASE 2: VARIATIONS & AUGMENTATION (80-100 additional scenarios)
===============================================================
For each base scenario, we created variations by changing parameters:

Original: CS + Astana + High Int'l + High Budget + Innovation → AITU

Variations generated:
  CS + Astana + LOW Int'l + High Budget + Innovation → AITU (int'l importance varies)
  CS + Other + High Int'l + High Budget + Innovation → AITU (city changes)
  CS + Astana + High Int'l + LOW Budget + Innovation → AITU (budget varies)

This creates robustness and handles edge cases where students have mixed profiles.


PHASE 3: AGGREGATION
====================
All scenarios are stored in a JavaScript array:

trainingData = [
  { spec: 'Computer Science', city: 'Astana', intl: 'High', budget: 'High', 
    priority: 'Innovation', best: 'aitu' },
  { spec: 'Computer Science', city: 'Astana', intl: 'Low', budget: 'High', 
    priority: 'Innovation', best: 'aitu' },
  { spec: 'Computer Science', city: 'Almaty', intl: 'High', budget: 'High', 
    priority: 'Quality', best: 'iitu' },
  // ... 200+ more scenarios
]

================================================================================
                         DECISION TREE STRUCTURE
================================================================================

The decision tree provides fast, rule-based routing before scoring:

DECISION_TREE = {
  specialization: {
    'Computer Science': {
      city: {
        'Astana': 'aitu',      // Astana students → AITU
        'Almaty': 'iitu',      // Almaty students → IITU
        'Other': 'aitu'        // Default → AITU
      }
    },
    'Engineering': {
      city: {
        'Almaty': 'kbtu',      // Almaty students → KBTU
        'Astana': 'iitu',      // Astana students → IITU (secondary choice)
        'Other': 'kbtu'
      }
    },
    'Business Management': {
      city: {
        'Almaty': 'uib',       // Almaty students → UIB
        'Astana': 'uib',       // Astana students → UIB (capital business hub)
        'Other': 'uib'
      }
    }
    // ... more specializations
  }
}

This tree provides an initial prediction, then the scoring algorithm refines it.

================================================================================
                        PREDICTION ALGORITHM
================================================================================

When a student submits the survey, the recommendation engine:

STEP 1: GET TREE PREDICTION
============================
Input: Student survey answers
Process: Look up specialization in decision tree → get city-based prediction
Output: Initial university recommendation (e.g., 'aitu')
Purpose: Quick baseline before detailed scoring

Example:
  Input: {spec: 'Computer Science', city: 'Astana', ...}
  Tree lookup: DECISION_TREE.specialization['Computer Science'].city['Astana']
  Output: 'aitu'


STEP 2: CALCULATE DETAILED SCORES
==================================
Input: Student survey answers + Training dataset
Process: Multi-stage scoring system

2.1) EXACT MATCH SCORING (50 points per match)
    Find all training scenarios that match ALL 5 parameters:
    spec, city, intl, budget, priority
    
    Example:
    Student answers: CS + Astana + High Int'l + High Budget + Innovation
    Training data has: CS + Astana + High Int'l + High Budget + Innovation → AITU
    Result: AITU gets +50 points

2.2) PARTIAL MATCH SCORING (30 points per match)
    Find training scenarios matching spec + city only:
    
    Example:
    Student: CS + Astana + Medium Int'l + Medium Budget + Career
    No exact match found
    Partial matches: CS + Astana scenarios
    Result: All universities in CS+Astana matches get +30 points

2.3) SPECIALIZATION KEYWORD MATCHING (20-25 points)
    Analyze specialization name for keywords:
    
    Keywords for AITU (Tech Innovation):
    - "computer", "software", "cybersecurity", "cloud"
    - "artificial", "data", "machine", "digital"
    Result: +20-25 points for AITU
    
    Keywords for KBTU (Engineering):
    - "engineer", "civil", "mechanical"
    - "oil", "gas", "architecture"
    Result: +30 points for KBTU
    
    Keywords for UIB (Business):
    - "business", "management", "finance"
    - "marketing", "entrepreneurship", "project"
    Result: +30 points for UIB

2.4) CITY BONUS (5-15 points)
    Almaty + any specialization:
      IITU gets +10 points (established in Almaty)
      KBTU gets +10 points (engineering hub)
      UIB gets +10 points (business hub)
    
    Astana + IT specializations:
      AITU gets +15 points (capital tech hub)

2.5) INTERNATIONAL BONUS (5-10 points)
    High International Importance:
      AITU gets +10 points
      IITU gets +5 points

2.6) PRIORITY BONUS (5-10 points)
    Innovation priority:
      AITU gets +10 points
    Quality priority:
      KBTU gets +8 points
    Reputation priority:
      UIB gets +8 points, KBTU gets +5 points
    Career priority:
      UIB gets +8 points, KBTU gets +5 points

TOTAL SCORING EXAMPLE:
======================
Student: Computer Science + Astana + High Int'l + High Budget + Innovation

Scoring breakdown:
  - Exact match: AITU +50 points (CS+Astana+High+High+Innovation found in training)
  - Specialization keywords: AITU +20, IITU +15
  - City bonus (Astana): AITU +15
  - International bonus: AITU +10, IITU +5
  - Priority bonus (Innovation): AITU +10
  
Final raw scores:
  AITU: 50 + 20 + 15 + 10 + 10 = 105
  IITU: 15 + 5 = 20
  KBTU: 0
  UIB: 0


STEP 3: NORMALIZE SCORES
========================
Convert raw scores to percentages (0-100):

Total = 105 + 20 + 0 + 0 = 125

Normalized:
  AITU: (105 / 125) * 100 = 84%
  IITU: (20 / 125) * 100 = 16%
  KBTU: (0 / 125) * 100 = 0%
  UIB: (0 / 125) * 100 = 0%


STEP 4: DETERMINE BEST MATCH & CONFIDENCE
==========================================
Best match: University with highest normalized score = AITU (84%)
Confidence: The percentage of the best match = 84%

Output:
{
  bestMatch: 'aitu',
  scores: {
    iitu: 16,
    aitu: 84,
    kbtu: 0,
    uib: 0
  },
  confidence: 84
}

This is displayed to the student as:
"Best Match: AITU (84% confidence)"
With breakdown showing all 4 universities' percentages.

================================================================================
                        HOW TO EXTEND THE SYSTEM
================================================================================

1. ADD NEW SPECIALIZATION
   - Add entry to decisionTree.specialization
   - Add 5-10 training scenarios for each city variant
   - Specify keywords for matching
   - Update scoring bonuses

2. ADD NEW UNIVERSITY
   - Add to scoring system (5 fields: iitu, aitu, kbtu, uib, newuni)
   - Create decision tree branches
   - Add 50+ training scenarios
   - Define specialization focus areas

3. IMPROVE PREDICTIONS
   - Collect real student data (survey → actual enrollment)
   - Compare predictions vs. actual choices
   - Adjust weights based on accuracy
   - Retrain decision tree branches

4. PERSONALIZATION
   - Add student characteristics (GPA, test scores, experience)
   - Weight training data by relevance
   - Add temporal factors (new programs, ranking changes)
   - Create user-specific recommendations
