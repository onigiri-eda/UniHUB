PROJECT OVERVIEW
================================================================================

Мы интегрировали GROK AI (от компании xAI) в качестве замены OpenAI GPT-3.5-turbo.
GROK теперь работает как интеллектуальный ассистент для помощи студентам в выборе
университета на основе данных PostgreSQL базы данных.

GROK FEATURES:
- Доступ к реальным данным университетов из PostgreSQL
- Поддержка функции сравнения двух университетов
- Быстрые и точные ответы на вопросы на русском языке
- Основан на последних данных университетов в Казахстане
- Интеграция с Backend API для получения свежих данных

   ├── universities - информация об университетах
   ├── academic_programs - программы обучения
   ├── admissions - требования к поступлению

================================================================================
                     CHAT FUNCTIONALITY - HOW IT WORKS
================================================================================

1. INITIALIZATION
   ├─ User opens index.html
   ├─ DOMContentLoaded event triggered
   ├─ initializeChat() creates chat widget
   └─ loadDatabaseData() fetches all data from /api/all-data

2. USER SENDS MESSAGE
   ├─ sendChatMessage() called
   ├─ User message added to chat
   ├─ setLoadingState(true) shows typing indicator
   └─ Checks if it's a comparison request

3. NORMAL QUERY FLOW
   ├─ buildSystemPromptWithDatabaseContext() creates system prompt with DB data
   ├─ Messages array prepared with full database context
   ├─ Fetch request to GROK API with:
   │  ├─ Authorization: Bearer {API_KEY}
   │  ├─ Model: grok-beta
   │  └─ Messages: [system_prompt, user_messages]
   ├─ GROK processes request and returns response
   └─ Response displayed in chat with bot-message class

4. COMPARISON REQUEST FLOW
   ├─ isComparisonRequest() detects keywords:
   │  ├─ "сравни", "сравнить", "vs", "разница", "отличие"
   │  └─ Requires mentioning 2+ universities: iitu, aitu, kbtu, uib
   ├─ Extract university names: uni1, uni2
   ├─ Fetch to /api/compare-universities?uni1={UNI1}&uni2={UNI2}
   ├─ Backend retrieves both universities with all related data:
   │  ├─ university1: { name, programs[], admission[], cooperation[] }
   │  └─ university2: { name, programs[], admission[], cooperation[] }
   ├─ formatComparisonResponse() formats structured comparison
   └─ Display comparison table in chat

================================================================================
                     API ENDPOINTS - DETAILS
================================================================================

1. GET /api/all-data
   Purpose: Load full database context for chat AI
   
   Response:
   {
     "universities": [
       {
         "id": "iitu",
         "name": "IITU",
         "description": "...",
         "location": "Almaty"
       },
       ...
     ],
     "programs": [
       {
         "university_id": "iitu",
         "name": "Computer Science",
         "level": "Bachelors"
       },
       ...
     ],
     "admission": [
       {
         "university_id": "iitu",
         "requirement": "..."
       },
       ...
     ],
     "cooperation": [
       {
         "university_id": "iitu",
         "country": "USA",
         "partner": "..."
       },
       ...
     ]
   }

   Usage:
   - Called once on page load
   - Cached in databaseData variable
   - Used in system prompt for GROK context

2. GET /api/compare-universities?uni1=IITU&uni2=KBTU
   Purpose: Get detailed comparison data between two universities
   
   Query Parameters:
   - uni1: First university name (IITU, AITU, KBTU, or UIB)
   - uni2: Second university name
   
   Response:
   {
     "university1": {
       "id": "iitu",
       "name": "IITU",
       "location": "Almaty",
       "programs": ["Computer Science", "Software Engineering", ...],
       "admission": ["UNT Score: 80+", "English: B2", ...],
       "cooperation": ["USA", "UK", "Canada", ...]
     },
     "university2": {
       "id": "kbtu",
       "name": "KBTU",
       "location": "Almaty",
       "programs": ["Engineering", "Architecture", ...],
       "admission": ["UNT Score: 75+", "Physics: strong", ...],
       "cooperation": ["Germany", "Switzerland", ...]
     }
   }
   
   SQL Query Used:
   ```sql
   SELECT u.*, 
          array_agg(DISTINCT ap.name) as programs,
          array_agg(DISTINCT adm.requirement) as admission,
          array_agg(DISTINCT ic.country) as cooperation
   FROM universities u
   LEFT JOIN academic_programs ap ON u.id = ap.university_id
   LEFT JOIN admissions adm ON u.id = adm.university_id
   LEFT JOIN international_cooperation ic ON u.id = ic.university_id
   WHERE LOWER(u.name) LIKE LOWER($1)
   GROUP BY u.id
   ```

================================================================================
                         ERROR HANDLING
================================================================================

1. Database Connection Error
   └─ loadDatabaseData() catches error
   └─ databaseData remains null
   └─ System prompt contains "Database not loaded"
   └─ GROK still provides general advice

2. GROK API Error
   └─ getGROKResponse() catches error
   └─ response.ok check fails
   └─ Error message: "Извините, произошла ошибка при обработке вашего запроса..."

3. Comparison Data Not Found
   └─ handleUniversityComparison() gets 404
   └─ Error message: "Извините, не удалось получить данные для сравнения..."

4. Invalid University Names
   └─ /api/compare-universities returns error if university not found
   └─ User informed: "One or both universities not found"

================================================================================
                         PERFORMANCE NOTES
================================================================================

1. Database Data Caching
   - All data loaded once on page load
   - No repeated database queries during chat
   - Reduces load and improves response time

2. API Rate Limiting
   - GROK API has rate limits (check xAI documentation)
   - Current implementation doesn't have request throttling
   - Consider adding if many concurrent users

3. Message History
   - All messages stored in chatMessages array
   - Full conversation history sent to GROK each time
   - Consider limiting to last N messages for long conversations

4. Network Dependencies
   - Requires connection to xAI API (https://api.x.ai)
   - Requires connection to local backend (http://localhost:5000)
   - Requires PostgreSQL database connection
   - Chat works offline for cached messages only

================================================================================
                      TROUBLESHOOTING GUIDE
================================================================================

Issue: Chat widget doesn't appear
Fix: Check if DOM loads, console for JavaScript errors

Issue: "Database not loaded" message
Fix: 
- Ensure server running on http://localhost:5000
- Check /api/all-data endpoint returns data
- Check browser console for CORS errors

Issue: GROK API returns error
Fix:
- Verify API_KEY is valid and active
- Check internet connection
- Review GROK API documentation
- Check if API rate limit exceeded

Issue: Comparison doesn't work
Fix:
- Ensure university names spelled correctly
- Use exact names: IITU, AITU, KBTU, UIB
- Check /api/compare-universities endpoint
- Verify PostgreSQL contains university data

Issue: Chat messages not sending
Fix:
- Check isLoading flag
- Ensure input field not empty
- Check browser console for errors
